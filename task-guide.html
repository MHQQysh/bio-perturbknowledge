任务书要求本项目对应证据
筛选 ≥30 篇，至少 10 项合格研究做实验提取保留 33 项筛选依据，归档 11 项研究的提取与文件核验，10 项的选定条件已联接。

≥3 个条件比较，≥1 项对照或消融三组 Jost 实算及换对照比较，另做准入规则消融和 Agent 两轮盲测。

02 / WORKFLOW

一条记录如何走完整个流程

  1. 01
    检索与初筛限定公开 CRISPRi 与单细胞表达，保留检索结果、来源以及纳入或排除理由。
  2. 02
    从研究材料提取到单个比较从论文、补充材料和公开样本提取实验背景、目标、对照、尺度和证据定位。
  3. 03
    联接真实细胞与表达矩阵用作者标签关联细胞条码。比较记录引用具体样本、扰动组、对照组和矩阵。
  4. 04
    核验并决定是否准入检查条码存在且唯一、组间互斥、数量、目标和对照标签、样本或批次、矩阵尺度与证据。
  5. 05
    计算响应并导出 Input / Target对有计数依据和可比对照的记录计算表达差，按基因顺序导出模型样例并校验。
  6. 06
    复跑、消融与验收保存运行日志和文件指纹，用同轮产物独立复算，并测试准入规则和 Skill 的作用。

核验形成回路。 证据不足时退回 Skill 1，指出缺失字段和要看的资料。标签已联接但尺度不明时可保留展示。补到证据后重新判定。

03 / AGENT DESIGN

两个 Skill 如何分工

Agent 负责选择材料、调用工具和决定退回。Skill 规定工作顺序和判断原则，Tool 完成可重复的读取与检查。

retrieve-link v1.1查看规范 ↗
Skill 1

检索、提取与关联

输入候选和来源。区分研究级与比较级信息，用作者标签把细胞联接到矩阵，为具体字段保存直接证据。

Tool 1 · read_record.py 读取实际细胞、检查分组并返回矩阵尺寸与回执。

移交 · 候选记录、来源定位、数据引用、读取回执、仍缺的字段。

validate-compare-export v1.1查看规范 ↗
Skill 2

验证、比较与导出

接收证据包，分别判断联接可用性和分析可用性，决定通过、仅展示或退回补证。

Tool 2 · verify_records.py 与 check_skill_handoff.py 检查两组关系、读取状态和证据一致性。

输出 · 准入决定、分析与导出文件、白名单及产物校验。双向交接协议
