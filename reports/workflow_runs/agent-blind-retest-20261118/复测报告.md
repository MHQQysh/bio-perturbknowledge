# 双 Skill 1.1 Agent 盲测复测

两项 Skill 根据首轮误引的类型更新。检索和提取阶段按字段区分直接依据与背景。验证阶段逐条回查引用，准入引用能分别支持联接和尺度的证据，退回引用明确指出缺口的材料。两项 Skill 通过格式校验。

本轮由三个新 Agent 分别执行基线、双 Skill 1.0 和双 Skill 1.1。各组使用独立上下文和相同的五个案例。资料包、任务、参考答案和评分程序的 SHA256 与首轮一致。原版 Skill 快照的指纹与首轮一致。先按匿名编号评分，再记录分组。

本轮显示新版在这五个案例上的引文更精确。两项 Skill 是依据这五个案例的首轮表现修改的，且每组只执行一次。独立新论文上的表现、主动找证据的表现和重复运行的稳定性仍需用新的数据另测。事实字段与准入判定在本轮三组均达到满分。
