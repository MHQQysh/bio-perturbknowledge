# 验证、比较与导出

根据[交接协议](../workflow-contract.md)接收证据包。Agent 在调用分析工具前写明判定及依据。

1. Tool 2 用 `scripts/verify_records.py` 或 `scripts/audit_workflow.py` 检查读取状态、细胞和对照关系、数量、记录指纹及证据。分别报告已存指纹检查、本次复读与作者结论核对。
2. 分别判定联接可用性与分析可用性。身份或对照缺证时退回并指出字段；联接通过但尺度不明时标为仅展示并退回尺度字段；同条件且 counts 依据明确时进入描述性计算。独立重复不足时保持描述性范围。退回判定直接引用说明缺口的材料。仅展示的判定需要同时支持已联接和尺度缺证，准入的判定需要支持联接通过和尺度明确。
3. 有至少三个同设计可比较条件时，调用 `analyze_responses.py` 并保留计数来源。用合并与单个对照子集的比较检验对照选择。如果做验证流程消融，使用共同材料和参考答案，并以同一指标比较两臂。只有实际执行之后才记录结果。
4. 由 `export_model.py` 导出 Input / Target。用字段白名单阻断扰动后读数和活性信息，核对基因顺序、维度与共享对照分组。运行 `validate_response_artifacts.py` 或同等逐项检查。把新计算与历史产物复核分别记账。

交付前逐字段回查引用，确认每个位置直接支持该字段值或准入条件中的一个必要判断。把只解释背景、研究总量或额外核验过程的引用移到说明中。整数值检查可以支持数值核验，尺度仍由明确的矩阵来源支持。
