# 检索、提取与关联

输入为检索范围或候选 ID、允许查阅的材料、可用数据位置。若接到退回，先读退回所指的字段与来源，再做定向补证。记录模式为新检索或归档复核。

1. 用 `scripts/discover_papers.py` 检索候选，或从已存台账按研究 ID 找到候选并声明复用。记录纳入依据：原始实验、任务指定扰动类型、单细胞 RNA 读出和公开入口。记录检索命中与人工判断的区别。
2. 从允许材料提取实验上下文、细胞标签粒度、对照定义和矩阵声明。以字段为单位记录直接来源、位置和取值。样本编号与计数尺度取自明确记载所选样本或矩阵的段落。比较组的数量和范围取自同一比较的标签表或读取回执。研究总数、整数取值检查和相关背景可放在说明里。按 schema 组织字段，将作者结论与项目结果各自保存。
3. Tool 1 使用 `scripts/read_record.py` 按候选比较记录取匹配行。保留调用与真实返回。若只复核已有记录，就把这次产物标为联接复核。只存在研究级证据时保留候选，不生成假定的细胞身份。
4. 向 `validate-compare-export` 移交候选证据包。每个字段只附能直接支持其取值或缺证状态的定位。需要多个互补证据时保留各项直接依据。规则见[交接协议](../workflow-contract.md)。

接到反馈时针对一个可定位的证据缺口复核。新增证据可产生新版本再提交。无新证据时记录检索范围和阻断原因，结束本次补证。
