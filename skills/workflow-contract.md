# 两项 Skill 的交接协议

每次任务保存来源审查、证据包、验证决定与工具回执。记录时间、Skill 路径和版本、本次读取的文件、实际命令和退出状态。

| 交接 | 必填信息 |
|---|---|
| Skill 1 → Skill 2 | 模式、研究 ID 或记录 ID、证据位置、只读数据引用、联接输出、仍缺少的字段 |
| Skill 2 → Skill 1 | 记录 ID、失败检查、缺失字段、已有证据、建议查看的具体材料位置 |
| Skill 2 → 项目产物 | 分析许可及范围、组别与尺度、实际命令、导出与核对结果、未解决的限制 |

状态依次为候选、已联接、可分析、已验证输出。证据不足可停在待补证或仅展示。退回只有发现新证据才重开。一个运行日志可以同时覆盖多个条件，但每条条件应有自己的判定。

字段证据对应具体取值或缺证依据。背景说明、研究总量与工具回执只在直接支持该字段时进入证据列表，其余写入说明。一个复合判定可引用分别支持各必要条件的材料。
